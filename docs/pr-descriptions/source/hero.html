Issue with composer send functionality

I was testing the new Inbox experience in the Agents window and noticed that there may be an issue with how the composer handles sending, which could potentially be confusing to users in some cases. To investigate, I first opened the developer tools and reloaded the window, then looked at composerWidget.ts and traced onDidSubmit through the session service, the inbox model, and the sidebar list, and initially I suspected a race between the focus tracker and the list refresh, but after adding logging it looked more like the send handler just never surfaces anything, although it might also be the way the sidebar re-renders after a new untitled session is created, so I'm not completely sure yet.

I then tried the same thing from a regular session and it seemed to work differently, which suggests the Inbox path is the problem, but I also checked whether the setting chat.agentSessions.inbox.enabled changes anything and it does not appear to, and I tried disabling extensions and running with a clean profile with the same result. Some possible fixes could be showing a toast, opening the session, or adding a link, but there may be accessibility implications for screen readers that would need to be considered as well, and I am not sure which approach the team would prefer here.

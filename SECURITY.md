# Security

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub:
**Security → Report a vulnerability** on this repository. Do not open a public
issue. You can expect a reply within a few days.

Reports about any `@rwoll` package published from this repository, or about its
release workflow, are in scope.

## Supported versions

Only the latest release of each package gets fixes.
